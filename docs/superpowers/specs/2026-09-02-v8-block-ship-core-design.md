# V8.0 方块船体破坏战斗系统设计

## 目标
把现有“整船贴图 + 整船 HP”战斗底层替换为“船 = 方块网格”的结构破坏系统。炮弹命中具体方块，方块受伤、破损并最终从视觉上消失；结构完整度过低时整船进入沉没。

## V8.0-A 范围
只实现最小可玩闭环：
1. 玩家旗舰与敌船均由二维方块网格生成和绘制。
2. 炮弹按真实飞行路径命中第一个存活方块。
3. 方块有 HP、受损态与死亡态；死亡方块不再绘制和碰撞。
4. 结构完整度低于阈值后沉船。
5. 炮弹命中产生木屑/火花/数字反馈。
6. 暂不接回复杂甲板战、登船、火焰传播、漏水、断裂块物理。

## 架构原则
- 方块是纯数据，不为每格创建 DOM、Canvas 对象或 Cocos Node。
- 每艘船只有一个 Ship 数据对象；Renderer 每帧批量绘制其存活方块。
- 结构/伤害逻辑与 Canvas 绘制分离，便于后续迁移到 Cocos Creator。
- V8 使用独立 `js/v8/`，不再继续在 V7 wrapper 链上叠补丁。
- 当前 V7.3 页面完整保留为 `legacy_v7.html`。

## 网格规格
- 玩家旗舰：20 × 34，cellSize=16px；实际有效格约 400～500。
- 突击艇：18 × 8，cellSize=16px。
- 炮舰：22 × 10，cellSize=16px。
- 巨舰：28 × 12，cellSize=16px。
- 通过模板 mask 形成船头尖、船尾宽、甲板层等轮廓，不要求矩形全部填满。

## 第一版 Cell 类型
- `hull`：外层船壳，HP 28。
- `deck`：内部甲板，HP 20。
- `core`：核心结构，HP 42，计入高权重完整度。
- V8.0-A 暂不实现 mast/cannon/powder 功能联动，但模板字段预留。

## 伤害与沉船
- 普通炮弹基础伤害 24。
- 炮弹命中第一个存活 cell，不直接穿透到内部。
- cell.hp/maxHp <= 0.5 时进入明显裂损色；hp <= 0 时 `alive=false`。
- 结构完整度：存活结构权重 / 初始结构总权重；hull=1、deck=1、core=2。
- 敌船完整度 <= 0.34 进入 sink。
- 玩家旗舰完整度 <= 0.24 判定失败。

## V8.0-A 战斗节奏
- 敌舰持续从右侧驶入。
- 玩家旗舰自动三炮轮射最近敌舰，约每 0.72 秒一次。
- 敌舰在进入攻击距离后以较慢频率向旗舰发炮，用同一方块伤害链演示玩家船体也会真实缺损。
- 击沉敌舰增加金币/击沉数并触发大爆炸。
- 点击敌舰可设置集火目标；点击空白取消。

## 视觉规则
- 存活完整块：船体基础色。
- 受损块：颜色变深 + 裂纹线。
- cell 被摧毁：当帧不再绘制，产生 4～8 个木屑粒子。
- 不再显示传统红色整船 HP 为主要信息；敌船上方显示“结构 xx%”作为调试/学习反馈。
