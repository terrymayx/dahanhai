# V9.0 · 矢量船体重构 设计规格

## 目标
把当前“逻辑格子直接画成像素方块”的表现彻底拆开：继续保留隐藏的格子耐久、破甲、穿透、部件和结构断裂作为战斗数据，但视觉改成连续、圆润、具有船头/船尾/船舷/甲板/桅杆特征的程序化 Canvas 矢量船体。

不生成、不依赖任何图片素材。

## 全局约束
- 逻辑碰撞继续使用 `V8ShipGrid`，不把贝塞尔曲线用于碰撞。
- 每个逻辑格仍有独立 HP，现有破甲后穿透语义不变。
- 不恢复镜头抖动、船体受击后坐或受击横摇。
- 保留低频 2 发齐射。
- 不加入进水，不创建 `leaks` / `flooding` / `draft`。
- 不新增舰型、关卡、登船战或图片资产。
- `legacy_v7.html` 不修改。

## 1. 视觉架构
新增 `js/v8/38_vector_ship.js`，提供独立矢量船绘制器。`40_render.js` 在模块存在时不再逐格调用 `drawCell()` 画船，而是把当前 ship 和 visual pose 交给矢量船绘制器。

逻辑层依旧是规则网格；视觉层不显示网格边界。

## 2. 船体轮廓
### 敌舰（横向）
- 长轴沿 local X。
- 左侧为收尖船首，右侧为圆钝船尾。
- 上下船舷使用二次/三次贝塞尔曲线形成鼓腹。
- sloop 更细长；gunship 中等；manowar 更宽厚、船尾更饱满。

### 玩家旗舰（纵向）
- 长轴沿 local Y。
- 上方船首收尖，下方船尾较宽。
- 船舷两侧连续圆滑，不出现阶梯状像素边。

## 3. 船体层次
每艘船至少绘制：
- 深色外船壳边缘/舷墙；
- 内缩甲板区域；
- 连续木板纹理线；
- 船首甲板与船尾楼层次；
- 桅杆圆柱截面与横桁；
- 浅色半透明帆面/帆影，用于强化“这是船”而非木块；
- 炮位用小型深色炮口/炮窗表示，不画成方格。

## 4. 真实破洞
矢量船先绘制到离屏 Canvas，再用 `destination-out` 按已摧毁逻辑格挖透明洞：
- hull 格形成较大的不规则缺口，靠外缘时自然咬掉船舷；
- deck 格形成较小甲板破洞；
- beam/core 等内部格形成较深暗洞；
- 多个相邻死亡格重叠后自动形成连续大缺口。

洞形使用确定性伪随机多边形/圆角形状，不能出现矩形方洞。

## 5. 受损但未摧毁
活着但 HP 下降的格子不显示格子边界，只在对应位置叠加：
- 裂纹线；
- 深浅焦痕；
- critical 时更明显的破口边缘与暗色损伤圈。

继续保留 `cell.flash` 命中闪光，但改为局部柔和高光，不使用方形 fillRect。

## 6. 残骸
现有 `debrisCluster` 逻辑不变，但渲染不再逐格画正方形：
- 小碎片画成长条木板、梯形船壳片；
- 多格 coherent cluster 画成相邻木板片组合并保留整体旋转/漂浮/下沉；
- 仍保留落水水花和生命周期。

## 7. 瞄准与点击
- 点击选择仍由 `Grid.pointHitsLiveCell` 和现有 local grid 映射完成。
- 准星位置保持与隐藏格中心对齐。
- 不要求玩家看到格子。
- V8.6 的部件耐久/结构应力模块可继续作为数据层存在，但 V9.0 视觉重构不依赖它完成。

## 8. HUD/版本
- 页面标题：`大航海时代 V9.0 · 矢量船体重构`
- HUD：`V9.0 · 矢量船体重构`
- 脚本缓存键统一 `?v=9.0.0`
- 入口加载 `js/v8/38_vector_ship.js`，顺序在 `40_render.js` 之前。

## 9. 性能
- 每艘船使用与船体包围盒相近的离屏 Canvas，最大约玩家 320×544 逻辑像素级别；按 DPR=1 的逻辑离屏尺寸绘制。
- 不创建每格 DOM/Node/Sprite。
- 不做每帧路径布尔运算；洞通过 Canvas composite 直接完成。
- 确定性洞形不存大量点数组，可按 gx/gy seed 即时生成。

## 验收
1. 正常运行时不再看到由正方形拼成的船体轮廓。
2. 玩家旗舰与三类敌舰都有连续圆滑、明显船型轮廓。
3. 船首/船尾/甲板/桅杆/帆/炮位具有可辨识层次。
4. 摧毁格会形成透明不规则破洞，相邻格能形成连续缺口。
5. 受损未毁格通过裂纹/焦痕表达，不显示方格边框。
6. 残骸不再是方块，而是木板/船壳碎片。
7. 瞄准、碰撞、独立耐久、破甲穿透、低频 2 发、无抖动、无进水保持不变。
8. V9.0 专项、现有 V8 回归、JS syntax、V6/V7 legacy 全部通过。
