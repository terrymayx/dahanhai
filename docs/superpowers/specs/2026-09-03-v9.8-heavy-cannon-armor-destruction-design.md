# V9.8 · 重炮装甲与破坏反馈系统 — 设计

日期：2026-09-03

## 目标

V9.8 让“炮攻”从单纯的伤害数字升级为完整的战斗参数：它同时决定穿甲能力、直击伤害、爆炸范围、外围受损程度、木屑/火球/震动反馈和关键部位破坏概率。敌船则通过船型装甲和部位装甲抵抗炮击。

必须保留现有规则：

- 一发炮弹只命中最前面的一个物理层，不能穿过前层继续伤害后层。
- 8px 物理格、缓存式船体渲染、火灾、进水、结构坍塌继续工作。
- 手动炮攻设置继续保留，默认手动；AUTO 仍为可选模式。
- 攻击力越高，爆炸范围仍然自动增大。
- 新系统不能重新引入明显掉帧。

## 1. 装甲模型

新增独立模块 `js/v8/34_v98_armor.js`。装甲只影响炮弹直击和炮弹爆炸，不影响火焰持续伤害、进水、结构应力等二次效果。

### 1.1 基础部位装甲

建议初始值：

| 部位 | 基础装甲 |
|---|---:|
| powder | 20 |
| mast | 24 |
| deck | 28 |
| rudder | 34 |
| cannon | 36 |
| hull | 42 |
| beam | 58 |
| core | 64 |

这会形成明确的命中差异：甲板容易炸坏/起火，船壳中等，主梁和核心最难破坏，火药舱一旦被命中则很脆弱。

### 1.2 船型装甲倍率

- sloop：0.85×
- gunship：1.08×
- manowar：1.28×
- player：1.00×

最终装甲：

`armor = 部位基础装甲 × 船型倍率`

### 1.3 穿甲分级

设：

`penetrationRatio = attackPower / armor`

命中分为四级：

- `< 0.60`：擦伤（Graze）
- `0.60–0.99`：受阻（Resisted）
- `1.00–1.49`：穿透（Penetrated）
- `>= 1.50`：重度穿透（Heavy）

建议直击有效伤害倍率：

- 擦伤：约 20%–35%
- 受阻：约 40%–70%
- 穿透：约 80%–105%
- 重度穿透：约 105%–135%

倍率随 penetrationRatio 连续变化，避免突然跳变。

V9.7.6 的炮攻 72 应有以下典型结果：

- 对 sloop 船壳：重度穿透
- 对 gunship 船壳：重度/正常穿透之间
- 对 manowar 船壳：正常穿透
- 对 manowar 主梁：受阻或临界穿透

因此大船仍能承受多炮，同时高炮攻依然有明显价值。

## 2. 伤害数据流

不修改 `G.damageCell(ship, cell, damage)` 的基础职责，因为火灾、结构应力、坍塌等很多系统都依赖它。

炮弹伤害改为：

`炮弹命中 -> V98Armor.resolveDirectHit() -> 得到有效伤害/装甲/穿甲等级 -> G.damageCell()`

爆炸伤害改为：

`爆炸候选格 -> V98Armor.resolveSplashHit() -> 有效爆炸伤害 -> G.damageCell()`

这样装甲只作用于炮击来源，不会错误降低火灾、结构断裂等伤害。

炮弹对象记录：

- `attackPower`
- `impactArmor`
- `impactRatio`
- `impactGrade`
- `effectiveDamage`

这些值供 HUD 和爆炸反馈模块读取。

## 3. 命中部位差异

V9.8 不新增复杂人员系统，只让现有物理部件产生更明显区别：

- hull：被穿透后更容易形成漏水破洞。
- deck：装甲较低，爆炸和起火表现更明显。
- mast：高炮攻命中时增加折断/失效感。
- rudder：破坏后继续影响敌船速度/操控效率。
- cannon：破坏后继续降低敌船射击效率。
- beam/core：装甲最高，但高炮攻重度穿透时结构应力反馈显著增强。
- powder：装甲低，穿透命中时提高现有爆炸/危险反馈，作为高价值弱点。

不改变“一炮一层”的碰撞规则。炮弹即使重度穿透并摧毁前层，也在该层停止；更深层只能由之后的炮弹通过真实破口击中。

## 4. 爆炸范围与性能

当前 `32_v954_impact_explosion.js` 会遍历整艘船 `ship.cells`。V9.8 改为局部网格查询。

### 4.1 局部候选格

根据攻击力计算 `baseRadius` 后，得到最大网格半径：

`scanRadius = ceil(baseRadius × 最大形变系数 + 2)`

只遍历：

`impactCell.gx ± scanRadius`

`impactCell.gy ± scanRadius`

通过 `ship.cellMap[gx + ',' + gy]` 直接取格子。

复杂度从“整船格数”下降为“大约爆炸局部面积”，特别适合高炮攻和大型战舰。

### 4.2 攻击力继续决定爆炸范围

保留 V9.7.4 的递减增长思路：

- 24 炮攻 ≈ 1.0× 基础爆幅
- 72 炮攻 ≈ 2.1×
- 更高炮攻继续增长
- 最大爆幅暂时限制在约 3.2×，避免一炮覆盖整艘大型船

装甲只降低某个格子的有效伤害，不缩小爆炸范围。因此高攻击力即使面对重装甲船，也依然能制造更大的“受影响区域”。

## 5. 重炮反馈

新增独立反馈模块，建议 `js/v8/42_v98_heavy_feedback.js`。

反馈强度由以下参数组合：

- attackPower
- blastRadiusScale
- penetrationRatio
- impactGrade
- 实际被影响/摧毁格子数量

表现：

- 炮攻越高：爆炸火团更大。
- 炮攻越高：木屑数量和飞行速度提高，但设置硬上限，防止对象爆炸。
- 重度穿透：加入更明显的中心冲击闪光。
- beam/core 重度受损：增强结构撕裂 FX。
- 命中船体时产生短促的船体冲击晃动。
- 屏幕震动保持轻量、短时间，不做持续大幅摇晃。

FX 数量继续受全局上限约束，不能因为攻击力 240 就创建数百额外对象。

## 6. 炮攻控制 UI

V9.7.6 的手动控制继续保留，但改造成更适合调试/游戏使用的组合控件：

- 范围滑条：24–240
- 数字输入框：精确输入
- `-10 / +10`
- `AUTO` 开关
- 修改立即生效，不需要必须点击“应用”才能看到滑条变化
- localStorage 继续保存炮攻和 AUTO 状态

滑条变化后，同步更新数字输入框；数字输入后同步更新滑条。

## 7. HUD / 目标信息

锁定敌船后，HUD 至少显示：

`炮攻 120 · 爆幅 2.6×`

以及目标：

`装甲 54 · 预计 重度穿透`

装甲值优先读取当前瞄准格子的类型；如果没有明确瞄准格，则显示目标船壳装甲。

命中后可短暂显示：

- 擦伤
- 受阻
- 穿透
- 重度穿透

不增加大型弹窗，保持移动端画面干净。

## 10. 验收测试

### 战斗逻辑

1. 炮攻 24 打 manowar 船壳：主要擦伤/受阻，不能表现成重炮。
2. 炮攻 72 打 sloop 船壳：明显重度破坏。
3. 炮攻 72 打 manowar 主梁：明显比打甲板更难破坏。
4. 炮攻 120+ 打 manowar 船壳：明显穿透、大范围损伤。
5. 一发炮弹仍只伤最前物理层，不能穿过前层继续伤后层。
6. 只有真实 HP=0 的 hull/deck 等破口继续进入现有进水系统。
7. 火灾伤害不受炮弹装甲公式二次减免。

### UI

1. 滑条、数字输入、±10 同步。
2. 刷新后手动炮攻保持。
3. AUTO 可选且状态保持。
4. HUD 装甲和预计穿透等级跟当前瞄准目标变化。

### 性能

1. manowar + 炮攻 240 的大爆炸不再遍历整艘船全部 cells。
2. 多艘敌船连续中炮时帧率不应明显低于 V9.7.6。
3. 木屑/爆炸 FX 数量继续受上限控制。

## 11. V9.8 完成标准

V9.8 完成后，玩家应能明显感受到：

`调高炮攻 -> 更容易穿甲 -> 爆炸更大 -> 更多格子受损 -> 更强木屑/冲击反馈 -> 更容易形成破洞、火灾、结构断裂和后续进水`

同时大型战舰凭借装甲仍能承受更多炮击，而不是单纯把 HP 做得非常高。
