# V9.9 · 真实船体结构与浮力破坏系统 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 V9.8 的装甲/爆炸系统升级为事件驱动的真实船体结构、局部材料疲劳、外海连通舱室进水和重心/浮力姿态系统，同时保持 8px 物理格与“一炮只打最前层”。

**Architecture:** 新增 4 个独立模块：`V99Material` 负责局部装甲/入射角/疲劳，`V99Structure` 负责局部承重/超载和大块断裂，`V99Compartments` 负责外海连通与 4–8 舱室进水，`V99Buoyancy` 负责重心/浮力中心、横倾/纵倾与沉没判据。现有炮弹、爆炸、渲染和 HUD 只通过这些模块的稳定接口接入；昂贵计算只在命中、拓扑变化或舱室阈值变化时触发。

**Tech Stack:** 原生 JavaScript、HTML5 Canvas、现有 V8/V9 网格/战斗/渲染模块、GitHub Actions Node 22 回归。

**Spec:** `docs/superpowers/specs/2026-09-03-v9.9-real-structural-buoyancy-destruction-design.md`

## Global Constraints

- 保留 8px 物理网格；不引入 6px、Box2D、XPBD、每帧全船有限元或真实流体求解。
- 一发炮弹只命中最前一个活物理格；只有浅角跳弹允许该炮弹继续飞行，且最多一次。
- 保留 V9.8 手动炮攻 24–240、AUTO、攻击力决定爆炸范围、火灾、局部爆炸与矢量缓存。
- 新增结构/进水计算必须事件驱动或按固定少量舱室更新；正常航行不得遍历整艘船。
- 大块断裂只作为独立高质量残骸，不再次进入精细炮弹命中系统。
