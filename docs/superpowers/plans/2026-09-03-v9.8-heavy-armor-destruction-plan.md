# V9.8 重炮装甲与破坏反馈系统 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不破坏现有 8px 物理格、首层碰撞、火灾/进水/结构系统和缓存性能优化的前提下，为炮击加入船型/部位装甲、穿透分级、局部爆炸查询、重炮反馈、滑条控制和穿甲预测 HUD。

**Architecture:** 新增 `V98Armor` 作为纯计算模块，只处理炮弹来源的直击/爆炸装甲解析；`20_projectiles.js` 与 `32_v954_impact_explosion.js` 在运行时读取该模块，基础 `G.damageCell()` 保持通用。爆炸候选格从整船遍历改为 `cellMap` 局部窗口查询；UI 与重炮反馈分别独立成模块，避免把战斗逻辑和渲染耦合。

**Tech Stack:** JavaScript ES5/ES6 IIFE modules, HTML5 Canvas 2D, DOM/CSS, localStorage, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-09-03-v9.8-heavy-armor-destruction-design.md`

## Global Constraints

- 一发炮弹只命中最前面的一个物理层，不能穿过前层继续伤害后层。
- 继续使用 8px 物理格、缓存式船体渲染、火灾、进水、结构坍塌。
- 手动炮攻默认启用；AUTO 仍可选。
- 攻击力越高，爆炸范围继续自动增大，最大爆幅约 3.2×。
- 装甲只影响炮弹直击与炮弹爆炸，不降低火焰、进水、结构应力等二次伤害。
- 高炮攻爆炸不得恢复为整船 `ship.cells` 扫描。

- [ ] **Step 3: Implement the armor model**

```js
const BASE_ARMOR={powder:20,mast:24,deck:28,rudder:34,cannon:36,hull:42,beam:58,core:64};
const SHIP_MULT={sloop:.85,gunship:1.08,manowar:1.28,player:1};
function armorFor(ship,cell){return (BASE_ARMOR[cell&&cell.type]||42)*(SHIP_MULT[ship&&ship.kind]||1);}
function gradeFor(r){return r<.60?'graze':r<1?'resisted':r<1.5?'penetrated':'heavy';}
function multiplierFor(r){
  if(r<.60)return .20+(r/.60)*.15;
  if(r<1)return .40+((r-.60)/.40)*.30;
  if(r<1.5)return .80+((r-1)/.50)*.25;
  return Math.min(1.35,1.05+(r-1.5)*.18);
}
```

`resolveDirectHit()` 使用 `attackPower * multiplierFor(ratio)`；`resolveSplashHit()` 使用 `rawDamage * multiplierFor(ratio)`，但穿透比仍用 `attackPower / armor`。
