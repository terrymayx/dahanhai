# V10.3 Real Broadside Salvo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace fixed-coordinate four-shot salvos with real port/starboard batteries where every gun is tied to a destructible cannon cell, has its own muzzle, firing arc and reload state, and fires sequentially from the ship’s current heading.

**Architecture:** Add `V103Broadside` as a focused battle subsystem layered on top of existing `V8Battle`, `V8Projectile`, `V8ShipGrid` and V10.2 ammo. `30_battle.js` keeps its legacy salvo as a fallback but delegates runtime firing/heading/reload to V103 when present. A separate DOM control module handles player turn controls and battery display without mixing UI into physics.

**Tech Stack:** JavaScript ES5/ES6 browser modules, Canvas 2D, DOM pointer/keyboard input, Node-based source/behavior contract tests, GitHub Actions, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-09-03-v10.3-real-broadside-salvo-design.md`

## Global Constraints

- Physical grid remains 8px.
- One projectile may damage only the foremost live physical layer.
- Existing breach permits only later projectiles through it.
- Player arc cap remains 32; enemy arc cap remains 22.
- V10.2 ammo multipliers remain unchanged and player attack remains 24–240.
- Enemy ammo remains `standard`.
- V10.1 fracture/bending/flood/fire/chunk systems remain active.
- Maximum gun slots per ship is 14.
- V10.3 cache key is `10.3.0`.
