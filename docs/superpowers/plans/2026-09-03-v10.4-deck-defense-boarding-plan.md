# V10.4 Deck Defense Boarding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a real-deck boarding-defense mode where an enemy ship deliberately collides with the player's ship, enemy sailors board the surviving player deck, the player directly controls a captain in melee, allied sailors defend with AI, and killing all boarders returns the game to naval combat.

**Architecture:** Keep V10.3 naval combat, projectile, damage, flooding, fracture, render and input modules intact. Add isolated V10.4 boarding modules that derive walkable space from the existing live player grid, wrap the final battle/update/render layers, and only take over captain input while `state.boarding.active` is true. Boarding is single-attacker only and uses bounded unit counts and dirty/revision-driven navigation caches for mobile performance.

**Tech Stack:** Vanilla JavaScript, Canvas 2D, Node-based regression scripts, GitHub Actions, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-09-03-v10.4-deck-defense-boarding-design.md`

## Global Constraints

- Player is always the defending side in V10.4; player cannot board or capture enemy ships.
- Boarding trigger is enemy-initiated real hull/deck contact after `boardingApproach`, not center-distance-only activation.
- Boarding fight remains on the player's current real ship grid; destroyed/detached cells are not walkable.
- Captain death loses the battle/game; killing all spawned boarders wins the boarding round.
- Only one enemy ship may be in boarding lock/wave with the player at a time.
- During boarding, the attached enemy ship must not continue normal full broadside firing.
- Existing V10.3 cannon, V10.2 ammo, 8px physical grid, one-shell-one-foremost-live-layer, flooding, fire, fracture and chunk rules must remain unchanged.
- Enemy active boarders <= 14, allied sailors <= 6, captain = 1.
- Walkability cache rebuilds only when the player-ship structural revision changes; no per-frame full-grid A*.
- V10.4 entry/cache version is `10.4.0`.

```js
function tryContact(state,enemy){
  if(!state||!enemy||enemy.state!=='active'||state.boarding.active)return false;
  const p=state.player;
  const rough=Math.hypot(enemy.x-p.x,enemy.y-p.y);

}
```
