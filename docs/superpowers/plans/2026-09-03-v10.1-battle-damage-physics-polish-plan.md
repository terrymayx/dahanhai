# V10.1 · 战损表现与物理稳定优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 V10.0 真实破坏链上增强主裂缝、渐进断船、分舱水面、低侧浸水翻覆、残骸二次破坏与连续破洞表现，同时保持移动端性能预算和一炮一层规则。

**Architecture:** 不重写底层物理，继续复用 V9.9/V10.0 的材料、12 截面弯矩、4–8 舱室、浮力和结构残骸数据。新增四个聚焦模块，并通过 revision/低频更新接入现有链条；旧模块只暴露必要钩子和缓存状态。

**Tech Stack:** Vanilla JavaScript, Canvas 2D, GitHub Pages, Node.js contract tests, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-03-v10.1-battle-damage-physics-polish-design.md`

## Global Constraints

- 物理网格保持 8px。
- 一发炮弹只命中最前一个存活物理层。
- 活动主裂缝 ≤ 32 / 船。
- 主裂缝传播约 5–7Hz / 船，单次仅检查端点 8 邻域。
- 舱室水量唯一来源是 `ship.__v99Compartments[].water`。
- 大型结构残骸全局 ≤ 18；残骸碰撞 ≤ 24 对 / 帧。
- 破洞/水面视觉都必须 revision 驱动，不允许逐帧全船重建。
- 手动炮攻 24–240、AUTO、V10.0 材料/进水/浮力链继续保留。
