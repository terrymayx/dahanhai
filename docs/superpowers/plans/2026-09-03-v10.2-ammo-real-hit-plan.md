# V10.2 · 舰炮弹药与真实命中系统 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 V10.1 已稳定的一炮一层、装甲/入射角、裂缝、断船、进水、火灾和大型残骸系统上，加入玩家可即时切换且无限使用的实心弹、链弹、爆裂弹，并让三种弹药产生明显、可测试的战术分工。

**Architecture:** 新增 `V102Ammo` 作为纯配置/计算层，炮弹仍由 `V8Projectile` 负责最前物理层命中，`V99Material` 负责入射角/装甲，`V954ImpactExplosion` 负责局部溅射，`V94FireDamage` 负责起火，`V101ChunkDamage` 负责大型残骸。玩家弹药选择保存在 battle state 的 `playerAmmoType` 中，并由独立 UI 模块持久化；已经发射的炮弹锁定发射时的 `ammoType`。

**Tech Stack:** 原生 JavaScript、Canvas 2D、Node.js `assert` 回归测试、GitHub Actions、GitHub Pages。

**Spec:** `docs/superpowers/specs/2026-09-03-v10.2-ammo-real-hit-design.md`

## Global Constraints

- 物理网格继续保持 8px。
- 一发炮弹只允许命中最前面的一个活物理层；本炮击毁前层后不得继续伤害第二活层。
- 后续炮弹可以穿过已经真实存在的破口。
- 玩家炮弹浅弧上限 32，敌舰炮弹浅弧上限 22。
- 玩家 24–240 炮攻继续作为三种弹药共用基础攻击力；AUTO 保留。
- 三种弹药无限使用，发射前可即时切换，无装填锁定、无库存。
- V10.2 只有玩家切换弹药；敌舰继续 V10.1 普通炮弹行为。
- 火焰 DOT 不读取 ammo profile，不受装甲减伤。
- 大型结构残骸全局上限继续为 18；V10.1 残骸碰撞/二次拆分规则保留。
- 正式入口升级为 V10.2，脚本缓存键统一为 `10.2.0`。
