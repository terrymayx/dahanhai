蔚蓝航路 · 持续航行·甲板守卫战

运行：解压后双击 index.html。当前在线与离线入口都直接进入最新“甲板守卫”模式，不再加载旧机动海战逻辑。

甲板守卫操作：
- 点击海上敌船：选择舰炮目标
- 点击甲板敌人：指定优先集火
- 上舷 / 中央 / 下舷：调动20名预备近战守军
- Space：舰炮齐射（开局可用，基础装填12秒）
- R：应急维修（2次）
- P / Esc：暂停
- F2：调试面板

说明：建议手机横屏运行。声音默认关闭，点击♫后由浏览器首次用户交互解锁音频。

【手机横屏围攻版】
- 本局计划14艘敌船，其中多数为快速运兵小艇。
- 同时活跃敌船最多5艘，但真实登船入口仍最多2个。
- 手机横屏：左下调预备队，右下舰炮/维修，中央甲板尽量无遮挡。

【10倍人海守船版】
- 我方可见战斗船员保持120人：60名射手 + 60名近战（含20名预备队）。
- 敌方各船拥有大量但有限的甲板远程人员与登船人员：小艇30远程+40登船，中船50+80，大船70+140。
- 同时活跃登船人员设220上限；普通入口8条轻量通行槽，大船12条。
- 仍只允许最多2个主要登船入口，重炮、预备队调度和守入口继续决定战局。

【远程交火接近版】
- 敌船从更远的右侧海域出现，不再使用旧版最高速度直接冲到我方船边。
- 接近分成“远程交火 → 减速闭合 → 靠舷调整 → 建立连接/登船”。
- 小艇较快，中型船更慢，大型登船舰最慢；接近靠舷位置时进一步降速。
- 我方60名射手会在岗位附近轻量移动、转向并持续射击；60名近战也会有巡位和补位动作。
- 20名预备队到达上舷/中央/下舷后形成分散队形，不再停在同一个坐标。
- 敌舰存活远程船员也会在甲板岗位附近移动、转向我方，并从真实位置发射箭矢或火枪弹。
- 敌船在接近途中就进入有效远程交火，靠舷后再保持相对位置建立跳板和登船。
