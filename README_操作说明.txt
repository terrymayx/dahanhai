蔚蓝航路 · 持续航行·甲板守卫战

运行：解压后双击 index.html。默认进入“甲板守卫”，顶部可切换“机动海战”对照模式。

甲板守卫操作：
- 点击海上敌船：选择舰炮目标
- 点击甲板敌人：指定优先集火
- 上舷 / 中央 / 下舷：调动2名预备近战守军
- Space：舰炮齐射（开局可用，基础装填12秒）
- R：应急维修（2次）
- P / Esc：暂停
- F2：调试面板
- 顶部“机动海战”：切回旧机动战斗模式

说明：建议横屏运行。声音默认关闭，点击♫后由浏览器用户交互解锁音频。


【手机横屏围攻版】
- 本局计划14艘敌船，其中11艘为快速运兵小艇。
- 同时活跃敌船最多5艘，但真实登船入口仍最多2个。
- 手机横屏：左下调预备队，右下舰炮/维修，中央甲板尽量无遮挡。


【10倍人海守船版】
- 我方可见战斗船员从12人提升到120人：60名射手 + 60名近战（含20名预备队）。
- 敌方各船甲板/登船人员按原配置至少10倍：小艇30远程+40登船，中船50+80，大船70+140。
- 同时活跃登船人员设220上限；每个入口8条轻量通行槽，大船12条，保持人海感同时控制手机成本。
- 仍只允许最多2个主要登船入口，重炮、预备队调度和守入口仍然决定战局。


【远程交火接近版】
- 敌船从更远处出现，按小艇/中船/大船不同速度逐步逼近，不再高速冲到船边。
- 接近分为远程交火、减速闭合、靠舷调整三个阶段；通常在靠舷前会有数秒持续箭火与火枪战。
- 我方60名射手、60名近战及敌舰远程船员都有轻量甲板移动；预备队到达防区后形成分散队形。
- 敌舰靠舷后继续保持相对位置，跳板和登船流程保持原规则。
